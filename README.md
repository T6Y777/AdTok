# AdTok

把抖音 / B 站网页版伪装成右下角广告弹窗的摸鱼神器。

## 技术栈

- **pywebview + WebView2**（Edge Chromium 内核，完整支持 H.264 视频解码）
- **pystray**（系统托盘）
- **纯 Win32 API**（全局热键，无第三方依赖）
- Python 3.13

## 功能

- 无边框弹窗样式，内容占满整个窗口，外观酷似右下角广告弹窗
- WebView2 内核加载抖音网页版，支持登录、视频播放（H.264 硬解）
- 全局老板键 `Ctrl + M` 一键显示/隐藏，隐藏时自动暂停视频
- 系统托盘常驻，左键显隐、右键菜单（显示/隐藏、退出）
- 窗口顶部 20px 隐形区域可拖拽移动
- `Ctrl + 滚轮` 等比例缩放窗口大小（保持 16:9），尺寸自动记忆
- 视频页默认 0.7 缩放，进入视频页自动适配，返回主页恢复
- `Ctrl + 加号/减号/0` 缩放视频页内容
- 按住鼠标中键拖动可平移网页内容，查看被裁剪部分
- 登录状态持久化保存，无需重复登录

## 快速开始

### 1. 安装依赖（首次运行）

```bat
.venv\Scripts\pip install -r requirements.txt
```

### 2. 启动

双击 `run.bat`，或命令行执行：

```bat
.venv\Scripts\python AdTok.py
```

> **注意**：Windows 10 可能需要安装 [WebView2 运行时](https://developer.microsoft.com/microsoft-edge/webview2/)，Windows 11 自带。

## 使用说明

| 操作 | 效果 |
|------|------|
| `Ctrl + M` | 显示 / 隐藏弹窗（隐藏时自动暂停视频） |
| `Ctrl + 滚轮` | 等比例缩放窗口大小（保持 16:9） |
| `Ctrl + 加号 / 减号` | 缩放视频页内容 |
| `Ctrl + 0` | 重置视频页内容缩放为 100% |
| 窗口顶部 20px 区域按住左键 | 移动窗口 |
| 按住鼠标中键拖动 | 平移网页内容 |
| 左键单击托盘图标 | 显示 / 隐藏弹窗 |
| 右键托盘图标 | 菜单（显示/隐藏、退出） |

## 默认窗口大小

默认尺寸 **337×190**（16:9 比例），贴死屏幕右下角。

- `Ctrl + 滚轮` 可等比例调整窗口大小，步进 20px 高度
- 最小尺寸 178×100，最大为屏幕高度的 90%
- 窗口大小和位置自动记忆，下次启动恢复
